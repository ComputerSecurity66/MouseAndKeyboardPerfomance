# 🖱️⌨️ Mouse And Keyboard Performance Test

A lightweight Windows batch utility that provides quick access to online tools for testing **mouse and keyboard performance**.

This project is designed for **PC users, technicians, hardware troubleshooting, and basic peripheral diagnostics**.

## ✨ Features

### 🖱️ Mouse Test

The Mouse Checker menu provides quick access to:

1. **Mouse DPI Analyzer**
   https://mousedpitest.com/

2. **Mouse Tester**
   https://mousetesters.com/

3. **MouseTester.io**
   https://mousetester.io/

4. **MouseTest**
   https://mousetest.app/

5. **XbitLabs**
   https://www.xbitlabs.com/

### ⌨️ Keyboard Test

The Keyboard Checker menu provides quick access to:

1. **Keyboard Test**
   https://www.onlinemictest.com/keyboard-test/

2. **KeyboardTester**
   https://www.keyboardtester.com/tester.html

3. **Typing.com**
   https://www.typing.com/

4. **Key-Test**
   https://en.key-test.ru/

5. **KeyboardTest.io**
   https://keyboardtest.io/

6. **keyboardtester.click**
   https://keyboardtester.click/

## 🚀 How to Use

### 1. Download the Project

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/mouse-keyboard-performance-test.git
```

Or download the repository as a ZIP file from GitHub.

### 2. Run the Batch File

Locate the `.bat` file and double-click it.

You can also run it from Command Prompt:

```cmd
MouseAndKeyboardPerformanceTest.bat
```

### 3. Select an Option

The main menu provides:

```text
=======================================
Mouse And Keyboard Performance Test
=======================================
1. Mouse Test
2. Keyboard Test
0. Exit
```

Select:

* `1` — Open the Mouse Test menu
* `2` — Open the Keyboard Test menu
* `0` — Exit the application

## 🖱️ Mouse Menu

The Mouse menu allows you to select different online mouse testing resources.

```text
==============================
Mouse Checker
==============================
1. Mouse DPI Analyzer
2. Mouse Tester
3. MouseTester.io
4. MouseTest
5. XbitLabs
0. Back
```

Selecting an option automatically opens the corresponding website in your default web browser.

## ⌨️ Keyboard Menu

The Keyboard menu provides several keyboard and typing testing resources.

```text
==============================
Keyboard Checker
==============================
1. Keyboard Test
2. KeyboardTester
3. Typing
4. Key-Test
5. KeyboardTest.io
6. keyboardtester.click
0. Back
```

Selecting an option automatically opens the selected website.

## 🎯 Purpose

This project provides a simple centralized menu for technicians and users who need to quickly access different mouse and keyboard testing websites.

Instead of manually searching for testing tools, users can launch the required resource directly from the batch application's menu.

## 🔐 Security & Privacy

This batch file does not install additional software or modify Windows system settings.

The application uses the Windows `start` command to open external websites in the user's default browser.

When using external testing websites, review their privacy policies and only provide information that is necessary for the test.
